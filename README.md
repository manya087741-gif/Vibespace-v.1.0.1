🌟 About Vibespace

Vibespace is a modern, feature-rich social media platform designed to bring people, creativity, entertainment, and communities together in one place.

Vibespace aims to provide users with an engaging digital experience where they can share their moments, upload short videos, connect with friends, communicate through messaging, enjoy live streaming, and build their own online community.

Our vision is to create a powerful social ecosystem where everyone gets the opportunity to express themselves, grow their audience, and turn their creativity into opportunities.

🚀 Getting Started

Follow these steps to run Vibespace locally.

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open Project Directory

cd Vibespace

3. Install Dependencies

npm install

4. Configure Environment Variables

Create a ".env" file using ".env.example" as a reference.

Add your required configuration values.

Important: Never upload passwords, API keys, database credentials or private secrets to GitHub.

5. Start Development Server

npm run dev

6. Build for Production

npm run build
